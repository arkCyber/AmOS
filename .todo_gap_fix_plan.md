# AmOS 8 Critical Gaps — Aerospace-Grade Fix Plan

> **Status**: TODO workspace tracker. Each gap is broken into 6 phases:
> 1. **Read** — exhaustive code reading + boundary discovery
> 2. **Implement** — type-safe Rust + bounded buffers + foreground-gated + honest boundaries
> 3. **Tests** — unit + integration (real UDS where applicable)
> 4. **FMEA** — failure-mode analysis with S/P/D scoring
> 5. **Scan gates** — wire the existing `hot-loop-scan` / `rust-panic-scan` / `fmea-gen` / `tauri-command-allowlist` gates
> 6. **Honesty boundary doc** — docs/CHANGELOG/TRACEABILITY_MATRIX entry naming what *isn't* claimed
>
> All implementations MUST follow the established repo conventions:
> - `#![cfg_attr(not(test), deny(clippy::unwrap_used, clippy::expect_used, clippy::panic))]`
> - typed error envelopes (`AmosError` w/ `ErrorCode` + `codes::RPC_FAILED`), never bare `String`
> - bounded strings/buffers (`MAX_*_BYTES` consts at command seams)
> - honest `None`/`HostOnly`/`Unattached`/`Unknown(...)` — never fabricate telemetry or capability
> - JNI global refs in `OnceLock`, every call re-attaches the thread (`amos_jni::attached`)
> - foreground-gated reads/pastes (window manager focus check)
> - FMEA entries via `scripts/fmea-gen.mjs` + `docs/FMEA.md` table growth
> - tests added: unit + one end-to-end through real UDS when the seam is `daemon -> bridge -> UI`
