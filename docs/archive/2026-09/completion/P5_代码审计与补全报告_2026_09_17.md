## 🔍 审计发现的问题

### 问题 1: changeAvatarTheme 使用错误的数据源
**位置**: `ContactsApp.svelte:320`

**原始代码**:
```typescript
const visibleIds = shown.map((c) => c.id);
```

**问题描述**:
- 使用 `shown`（搜索结果的扁平列表）而非实际渲染的联系人
- 当用户搜索时，动画会应用到未渲染的联系人
- 实际渲染使用的是 `groups` (分组后的联系人)

**修复**:
```typescript
const visibleIds = groups.flatMap((grp) => grp.items.map((c) => c.id));
```

**影响**: 确保翻转动画只应用到当前可见的联系人，避免不必要的状态更新

---

### 问题 2: 单击触发预览与长按功能冲突
**位置**: `ContactsApp.svelte:354`

**原始代码**:
```typescript
else {
  // Single click: trigger bounce animation and preview
  animateAvatar(contactId);
  previewAvatar(contactId);  // ❌ 与长按预览功能重复
  lastClickTime = now;
  lastClickTarget = contactId;
}
```

**问题描述**:
- 单击和长按都触发预览，造成交互混乱
- 用户期望：单击 = 弹跳，长按 = 预览

**修复**:
```typescript
else {
  // Single click: trigger bounce animation only (long press handles preview)
  animateAvatar(contactId);
  lastClickTime = now;
  lastClickTarget = contactId;
}
```

**影响**: 清晰的交互层次，单击仅弹跳，长按才预览

### 问题 3: 双击时未取消长按计时器
**位置**: `ContactsApp.svelte:346`

**原始代码**:
```typescript
if (isDoubleClick) {
  spinningAvatarId = contactId;
  // ❌ 未取消长按计时器，可能导致预览和旋转同时触发
  ...
}
```

**问题描述**:
- 双击时长按计时器仍在运行
- 可能导致 500ms 后预览和旋转动画同时出现

**修复**:
```typescript
if (isDoubleClick) {
  cancelLongPress();  // ✅ 立即取消长按
  spinningAvatarId = contactId;
  ...
}
```

**影响**: 防止双击和长按预览冲突

---

### 问题 4: setTimeout 回调未检查状态
**位置**: 多处

**原始代码**:
```typescript
setTimeout(() => {
  animatingAvatarId = null;  // ❌ 无条件清除，可能清除其他动画
}, 600);
```

**问题描述**:
- 如果快速触发多个动画，后续的 `setTimeout` 可能清除新动画的状态
- 边缘情况：用户在 600ms 内点击另一个头像

**修复**:
```typescript
setTimeout(() => {
  if (animatingAvatarId === contactId) {  // ✅ 检查是否仍是当前动画
    animatingAvatarId = null;
  }
}, 600);
```

**影响**: 防止状态竞争，确保动画不会被错误清除

---

### 问题 5: 长按计时器未清除
**位置**: `ContactsApp.svelte:367`

**原始代码**:
```typescript
longPressTimer = window.setTimeout(() => {
  if (longPressTarget === contactId) {
    previewAvatar(contactId);
    longPressTarget = null;  // ✅ 已清除目标
    // ❌ 未清除计时器引用
  }
}, 500);
```

**问题描述**:
- `longPressTimer` 引用未清除，虽然不影响功能，但不够严谨

**修复**:
```typescript
longPressTimer = window.setTimeout(() => {
  if (longPressTarget === contactId) {
    previewAvatar(contactId);
    longPressTimer = null;      // ✅ 清除计时器引用
    longPressTarget = null;
  }
}, 500);
```

**影响**: 代码更清晰，便于调试
