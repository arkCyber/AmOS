### 1. 长按全屏预览

**交互逻辑**:
- 按下头像（触摸或鼠标）启动 500ms 计时器
- 移动或释放前如果达到 500ms，触发全屏预览
- 移动手势（`touchmove`/`mouseleave`）立即取消长按

**实施位置**: `ContactsApp.svelte`

```typescript
// 长按状态管理
let longPressTimer = $state<number | null>(null);
let longPressTarget = $state<string | null>(null);

// 启动长按检测
function startLongPress(contactId: string) {
  return (e: Event) => {
    e.preventDefault();
    longPressTarget = contactId;
    longPressTimer = window.setTimeout(() => {
      if (longPressTarget === contactId) {
        previewingAvatarFor = contactId;
        longPressTimer = null;
        longPressTarget = null;
      }
    }, 500);
  };
}

// 取消长按
function cancelLongPress() {
  if (longPressTimer) {
    clearTimeout(longPressTimer);
    longPressTimer = null;
    longPressTarget = null;
  }
}
```

**事件绑定**:
```svelte
<button
  ontouchstart={() => startLongPress(c.id)}
  ontouchend={cancelLongPress}
  ontouchmove={cancelLongPress}
  onmousedown={() => startLongPress(c.id)}
  onmouseup={cancelLongPress}
  onmouseleave={cancelLongPress}
>
```

**全屏预览 UI**:
```svelte

  <div class="fixed inset-0 z-50 flex items-center justify-center bg-black/80 backdrop-blur-sm">
```

### 2. 主题切换翻转动画

**交互逻辑**:
- 用户切换 Emoji 主题（动物→食物→自然→符号→表情→旗帜→运动）
- 所有可见头像按顺序触发 3D 翻转动画，间隔 30ms（波浪效果）
- 每个头像翻转 600ms，使用 `rotateY(360deg)`

**实施位置**: `ContactsApp.svelte`

```typescript
let flippingAvatarId = $state<string | null>(null);

async function changeAvatarTheme(theme: AvatarTheme) {
  avatarTheme = theme;
  setAvatarTheme(theme);
  
  // 获取所有可见联系人 ID
  const visibleIds = displayedGroups.flatMap(g => 
    g.contacts.slice(0, g.contactLimit).map(c => c.id)
  );
  
  // 按顺序触发每个头像的翻转动画
  for (let i = 0; i < visibleIds.length; i++) {
    setTimeout(() => {
      flippingAvatarId = visibleIds[i];
      setTimeout(() => {
        if (flippingAvatarId === visibleIds[i]) flippingAvatarId = null;
      }, 600); // 翻转动画持续时间
    }, i * 30); // 30ms 间隔，创造波浪效果
  }
  
  avatarThemeMenuOpen = false;
}
```

**CSS 动画** (`tailwind.config.js`):
```javascript

    "0%": { transform: "rotateY(0deg)" },
    "100%": { transform: "rotateY(360deg)" },
  },
},

  "avatar-flip": "avatar-flip 0.6s ease-in-out",
}
```

**HTML 应用**:
```svelte

  style:transform-style="preserve-3d"
>
```

### 3. 连续旋转动画

**交互逻辑**:
- 检测双击（两次点击间隔 < 500ms，且目标相同）
- 触发 1.2 秒旋转动画，中途放大 10%（`scale(1.1)`）

**实施位置**: `ContactsApp.svelte`

```typescript
let spinningAvatarId = $state<string | null>(null);
let lastClickTime = $state<number>(0);
let lastClickTarget = $state<string | null>(null);

function handleAvatarClick(contactId: string) {
  return (e: Event) => {
    const now = Date.now();
    const isDoubleClick = 
      lastClickTarget === contactId && 
      now - lastClickTime < 500;

    if (isDoubleClick) {
      // 双击：触发旋转动画
      spinningAvatarId = contactId;
      setTimeout(() => {
        if (spinningAvatarId === contactId) spinningAvatarId = null;
      }, 1200);
    } else {
      // 单击：触发弹跳动画并预览
      animatingAvatarId = contactId;
      setTimeout(() => {
        if (animatingAvatarId === contactId) animatingAvatarId = null;
      }, 600);
      previewingAvatarFor = contactId;
    }

    lastClickTime = now;
    lastClickTarget = contactId;
  };
}
```

**CSS 动画** (`tailwind.config.js`):
```javascript
keyframes: {
  "avatar-spin": {
    "0%": { transform: "rotate(0deg) scale(1)" },
    "50%": { transform: "rotate(180deg) scale(1.1)" },
    "100%": { transform: "rotate(360deg) scale(1)" },
  },
},
animation: {
  "avatar-spin": "avatar-spin 1.2s ease-in-out",
}
```

## 📊 性能优化

### 1. 动画性能
- **使用 CSS 动画**（而非 JS 定时器），利用 GPU 加速
- **`transform` 属性**（`scale`, `rotate`, `rotateY`）不触发重排
- **`will-change` 隐式优化**（浏览器为 `transform` 预分配图层）

### 2. 错峰策略
- **30ms 间隔**在 100 个联系人下总时长 3.57 秒
- **避免同时渲染**所有动画，降低瞬时 CPU 负载
- **使用 `setTimeout` 批处理**，而非一次性设置所有状态

### 3. 长按防抖
- **移动事件立即取消**，避免误触
- **单一计时器管理**，防止内存泄漏
