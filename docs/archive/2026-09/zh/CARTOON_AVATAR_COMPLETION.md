### 2. 稳定哈希算法

**函数**: `avatarEmoji(name: string): string`

**实现细节**:
```typescript
export function avatarEmoji(name: string): string {
  let hash = 0;
  for (const ch of cleanName(name)) {
    hash = ((hash << 5) - hash + ch.codePointAt(0)!) | 0;
  }
  return AVATAR_EMOJIS[Math.abs(hash) % AVATAR_EMOJIS.length];
}
```

**算法特性**:
- ✅ 确定性：相同姓名总是得到相同的 Emoji
- ✅ 分布均匀：左移 5 位 + 减法混合，确保 hash 分布均匀
- ✅ 跨平台一致：使用标准 JavaScript 位运算
- ✅ 高性能：O(n) 时间复杂度，n 为姓名长度

**测试验证**:
```typescript
avatarEmoji("张三")     // => 总是返回相同的 Emoji（如 🐻）
avatarEmoji("李四")     // => 总是返回相同的 Emoji（如 🐱）
avatarEmoji("John Doe") // => 总是返回相同的 Emoji（如 🦊）
```

## 🎨 设计决策说明

### 为什么选择动物 Emoji？

**优势**:
1. ✅ **中性友好**: 不涉及性别、种族、宗教等敏感问题
2. ✅ **普遍认知**: 动物形象跨文化通用
3. ✅ **情感亲和**: 可爱动物容易产生亲近感
4. ✅ **数量充足**: 50 种动物提供足够的辨识度

**备选方案（未采用）**:
- ❌ 人物 Emoji：涉及肤色、性别敏感问题
- ❌ 表情 Emoji：辨识度低，视觉噪音大
- ❌ 食物 Emoji：缺乏个性，不适合代表人物
- ❌ 符号 Emoji：抽象度高，辨识度差

### 为什么保留渐变背景？

**理由**:
1. ✅ **视觉层次**: 渐变背景增强头像的立体感
2. ✅ **色彩丰富**: 360° 色相环提供无限色彩组合
3. ✅ **辅助辨识**: 即使 Emoji 相同，背景色不同仍可区分
4. ✅ **iOS 设计**: 符合 iOS 原生联系人应用的视觉风格

**效果**:
- 🐻 在蓝绿渐变背景上
- 🦊 在橙红渐变背景上
- 🐼 在紫粉渐变背景上
- 每个联系人都有独特的"背景色 + Emoji"组合
