## 🎯 任务 1：自定义头像上传

### 功能概述
完整实现用户自定义头像上传功能，支持图片选择、压缩、存储和预览。

### 核心特性
1. **图片处理引擎**
   - 自动裁剪为正方形
   - 智能压缩（缩略图 128×128 + 完整图 512×512）
   - Canvas API 客户端处理
   - 支持 JPEG 质量控制

2. **混合存储方案**
   - 缩略图：Base64 编码，< 10KB（列表显示）
   - 完整图：Base64 编码，< 100KB（详情/预览）
   - 未来可扩展：文件系统混合存储

3. **完整 UI 集成**
   - 悬停显示控制按钮（上传 + 删除）
   - 右键/长按打开上传对话框
   - 点击头像全屏预览
   - 上传进度提示
   - 键盘导航支持（Escape/Enter 关闭预览）

4. **安全性**
   - 文件类型白名单验证
   - 大小限制（10MB）
   - 完整错误处理
   - 用户友好的错误提示
