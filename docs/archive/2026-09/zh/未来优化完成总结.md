### 1. 自定义头像上传（待定）

**当前状态**: 已完成技术评估，暂未实施

**技术方案**:
- 推荐方案：混合存储（缩略图 Base64 + 原图懒加载）
- 图片裁剪：Canvas API 裁剪为 1:1 正方形
- 压缩优化：缩略图 < 10KB，原图 < 100KB
- vCard 集成：导出时编码 `PHOTO` 字段

**工作量**: 7-10 天开发 + 2-3 天测试 = **10-13 天**

**风险与缓解**:
- 存储空间膨胀 → 限制图片尺寸和质量
- 序列化性能 → 使用缩略图 + 懒加载
- 隐私泄露 → 本地存储，不上传云端

**建议**: 先发布当前版本，收集用户反馈后再决定是否实施
