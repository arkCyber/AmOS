## 🎯 核心概念

### 快捷指令 (Shortcut)
一个包含多个操作的自动化序列，可以通过触发器执行。

### 操作 (Action)
执行特定任务的单元，如发送通知、打开应用、计算等。

### 触发器 (Trigger)
启动快捷指令的条件，如 Siri 语音、时间、位置等。

### 变量 (Variable)
在操作之间传递数据的容器。

## 🔗 变量引用

### 内置变量
- `{input}` - 快捷指令的输入数据
- `{output}` - 上一个操作的输出
- `{date}` - 当前日期 (本地格式)
- `{time}` - 当前时间 (本地格式)

### 自定义变量
- `{var:name}` - 引用名为 "name" 的变量

### 示例
```typescript
操作 1: 文本 "Hello"
操作 2: 设置变量 "greeting" = {output}
操作 3: 文本 "{var:greeting}, World!"
// 结果: "Hello, World!"
```

## ⚙️ 高级技巧

### 1. 链式操作
每个操作的输出会自动传递给下一个操作：
```typescript
文本 "hello" → 大写转换 → 添加前缀 "MSG: "
// 结果: "MSG: HELLO"
```

### 2. 条件逻辑
使用条件判断实现分支：
```typescript
获取电量 → 条件判断 (电量 < 20)
  - 真: 通知 "电量不足，请充电"
  - 假: 通知 "电量充足"
```

### 3. 循环处理
批量处理数据：
```typescript
获取联系人列表 → 循环 (每个联系人)
  - 发送短信 "新年快乐！"
```

### 4. 错误处理
操作失败时继续执行：
```typescript
打开应用 "Safari"
  - 失败: 通知 "无法打开应用"
  - 继续下一步...
```

## 🐛 常见问题

### Q: 快捷指令执行失败怎么办？
A: 检查操作日志，确认所需权限已授予，验证参数格式正确。

### Q: 如何分享快捷指令？
A: 使用导出功能生成 `.shortcut` 文件，通过 AirDrop 或云盘分享。

### Q: Siri 无法识别快捷指令？
A: 确保在设置中配置了 Siri 短语，且短语唯一且易识别。

### Q: 如何备份快捷指令？
A: 数据自动保存在 `amos.shortcuts`，可通过 iCloud 同步。

### Q: 可以在锁屏状态下运行吗？
A: 可以，但需在快捷指令设置中开启"锁屏运行"选项。

## 📚 API 参考

### TypeScript 使用

```typescript
import {
  createShortcut,
  executeShortcut,
  loadShortcuts,
  type Shortcut,
} from "@/lib/shortcuts";

// 创建快捷指令
const shortcut = createShortcut("我的快捷指令", {
  icon: "⚡",
  color: "#007AFF",
  description: "这是一个示例",
});

// 添加操作
shortcut.actions = [
  {
    id: "1",
    actionId: "text.text",
    parameters: { text: "Hello World" },
  },
];

// 执行快捷指令
const result = await executeShortcut(shortcut.id);
if (result.success) {
  console.log("执行成功:", result.output);
} else {
  console.error("执行失败:", result.error);
}

// 加载所有快捷指令
const shortcuts = loadShortcuts();
console.log(`共有 ${shortcuts.length} 个快捷指令`);
```
