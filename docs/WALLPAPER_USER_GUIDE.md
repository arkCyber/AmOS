# AmOS 壁纸功能用户指南

> 版本：1.0
> 适用于：AmOS Desktop 桌面形态
> 更新时间：2026-09-16

---

## 一、功能概览

AmOS 提供完整的壁纸自定义功能，包括：

✅ **6 种内置壁纸** - 专业设计的预设壁纸  
✅ **自定义壁纸** - 使用任意图片 URL 或上传本地图片  
✅ **4 种显示模式** - 控制壁纸的透明度、模糊和饱和度  
✅ **独立锁屏壁纸** - 锁屏界面使用不同的背景  
✅ **主题自适应** - 暗黑/明亮主题自动切换壁纸  
✅ **安全保护** - 自动过滤危险的图片源

## 二、设置主屏壁纸

### 2.1 打开壁纸设置

**方法 1**：通过设置应用
1. 打开 Dock 中的"设置"应用
2. 点击左侧菜单的"壁纸"
3. 看到"壁纸"设置卡片

**方法 2**：通过桌面右键菜单
1. 在桌面空白处右键
2. 选择"更改壁纸…"
3. 自动打开设置应用的壁纸页面

**方法 3**：通过照片应用
1. 打开"照片"应用
2. 选择一张照片
3. 点击"设为壁纸"按钮

### 2.2 选择内置壁纸

AmOS 提供 6 种预设壁纸：

| 壁纸 | 说明 | 适用场景 |
|------|------|----------|
| **自动** | 根据暗黑/明亮主题自动切换 | 推荐日常使用 |
| **暗黑** | 深色调壁纸 | 暗黑主题专用 |
| **明亮** | 浅色调壁纸 | 明亮主题专用 |
| **风景** | 自然风景照片 | 宽屏显示器 |
| **黎明** | 日出日落色调 | 温暖氛围 |
| **深渊** | 深邃蓝色调 | 专注工作 |

**操作步骤**：
1. 在壁纸设置卡片中
2. 点击任一预设按钮（如"风景"）
3. 壁纸立即生效，无需保存

### 2.3 使用自定义壁纸

#### 方式 1：使用图片 URL

1. 在"自定义"输入框中粘贴图片 URL
2. 点击"应用"按钮
3. 壁纸立即切换

**支持的 URL 格式**：
- `https://example.com/image.jpg`（推荐）
- `http://example.com/image.png`
- `data:image/jpeg;base64,...`（Base64 编码）
- `blob:...`（浏览器内部对象）

**不支持的格式**（安全限制）：
- ❌ `file:///path/to/image.jpg`（本地文件路径）
- ❌ `javascript:...`（脚本注入）
- ❌ `data:text/html,...`（非图片数据）

#### 方式 2：上传本地图片

1. 在壁纸设置卡片中
2. 点击"上传"按钮（或拖拽图片到输入框）
3. 选择本地图片文件
4. 图片自动上传并应用

**限制**：
- 文件大小：≤ 2.5 MB
- 支持格式：JPG、PNG、GIF、WebP

### 2.4 调整显示模式

壁纸的显示方式可以通过 4 种"背景显示"模式调整：

| 模式 | 透明度 | 模糊 | 饱和度 | 亮度 | 适用场景 |
|------|--------|------|--------|------|----------|
| **幽灵** | 58% | 9px | 92% | 102% | 默认，图标清晰可见 |
| **柔和** | 80% | 3px | 100% | 105% | 保留壁纸细节 |
| **静音** | 42% | 14px | 60% | 96% | 极简风格 |
| **鲜艳** | 95% | 0px | 108% | 100% | 壁纸为主角 |

**操作步骤**：
1. 在壁纸设置卡片的"背景显示"区域
2. 点击任一模式按钮
3. 效果立即预览

**推荐搭配**：
- 复杂图案壁纸 → 使用"静音"模式
- 简约壁纸 → 使用"鲜艳"模式
- 工作场景 → 使用"幽灵"模式

## 三、设置锁屏壁纸

### 3.1 独立锁屏背景

锁屏界面可以使用与主屏不同的壁纸：

1. 打开"设置" → "壁纸"
2. 找到"锁屏背景"设置卡片
3. 选择内置壁纸或上传自定义图片
4. 锁屏时生效

**建议**：
- 锁屏壁纸选择较暗的图案，便于查看时间和日期
- 避免使用过于鲜艳的颜色

### 3.2 清除锁屏壁纸

如果想让锁屏使用与主屏相同的壁纸：

1. 在"锁屏背景"设置卡片中
2. 点击"清除"按钮
3. 锁屏壁纸回退到主屏壁纸

---

## 四、显示/隐藏壁纸

### 4.1 临时隐藏壁纸

如需专注工作，可以临时隐藏壁纸：

**方法 1**：通过菜单栏
1. 点击菜单栏的"显示"（View）
2. 选择"切换壁纸"（Toggle Wallpaper）
3. 壁纸消失，桌面显示纯色背景

**方法 2**：通过快捷键
- 暂无快捷键（计划中）

**恢复壁纸**：
- 重复上述操作即可恢复

### 4.2 隐藏其他元素

除了壁纸，还可以隐藏：

- **桌面图标**：View → 切换图标
- **舞台挂件**（如时钟）：View → 切换舞台挂件

## 五、高级技巧

### 5.1 主题自适应壁纸

选择"自动"壁纸后：
- 明亮主题 → 自动显示 `wallpaper-light.png`
- 暗黑主题 → 自动显示 `wallpaper-dark.png`

**切换主题**：
1. 打开"设置" → "外观"
2. 切换"暗黑模式"开关
3. 壁纸自动切换

### 5.2 快速从照片设为壁纸

1. 打开"照片"应用
2. 浏览并选择一张照片
3. 点击底部的"设为壁纸"按钮
4. 提示"已设为壁纸"
5. 返回桌面查看效果

### 5.3 使用 Base64 壁纸

适用于需要离线使用或嵌入配置的场景：

1. 将图片转换为 Base64 编码
2. 在自定义壁纸输入框中粘贴：
   ```
   data:image/jpeg;base64,/9j/4AAQSkZJRg...
   ```
3. 点击"应用"

**工具**：可使用在线 Base64 编码器

## 六、常见问题

### Q1: 为什么无法使用本地文件路径？

**答**：出于安全考虑，AmOS 不支持 `file://` 协议。请使用以下替代方案：
- 上传图片到图床，使用 HTTPS URL
- 使用"上传"功能上传本地图片
- 使用 Base64 编码

### Q2: 上传的图片保存在哪里？

**答**：上传的图片转换为 Base64 编码后保存在 `amos.settings` 配置中，无需额外文件。

### Q3: 如何备份壁纸设置？

**答**：壁纸设置存储在 `amos.settings`，可通过以下方式备份：
1. 打开"设置" → "系统" → "导出设置"（计划中）
2. 或手动复制 `~/.config/amos/settings.json`

### Q4: 壁纸模糊，如何调整？

**答**：在"背景显示"中选择"鲜艳"模式，模糊度为 0。

### Q5: 能否设置动态壁纸（视频）？

**答**：当前版本不支持，计划在未来版本中实现。

### Q6: 壁纸切换有动画吗？

**答**：当前版本是即时切换。未来可能添加淡入淡出效果。

## 七、技术参考

### 7.1 壁纸文件位置

内置壁纸存储在：
```
/Applications/AmOS.app/Contents/Resources/wallpapers/
├── wallpaper-dark.png
├── wallpaper-light.png
├── wallpaper-landscape.png
├── wallpaper-dawn.png
└── wallpaper-abyss.png
```

### 7.2 配置文件格式

壁纸设置保存在 `amos.settings`：

```json
{
  "wallpaper": "landscape",
  "background": "soft",
  "lockWallpaper": "dark",
  "view": {
    "showWallpaper": true
  }
}
```

### 7.3 程序化设置（开发者）

```typescript
import { writeStoreValue } from "./lib/amosStore";

// 设置壁纸
writeStoreValue("amos.settings", {
  wallpaper: "https://example.com/bg.jpg",
  background: "vivid"
});

// 隐藏壁纸
writeStoreValue("amos.settings", {
  view: { showWallpaper: false }
});
```

## 九、安全提示

⚠️ **URL 安全**：
- 仅使用可信来源的图片 URL
- 避免使用不明来源的 Base64 编码

⚠️ **隐私保护**：
- 上传的图片以 Base64 存储在本地，不会上传到服务器
- 如使用外部 URL，请确保链接不含隐私信息

⚠️ **自动过滤**：
- AmOS 自动拒绝 `javascript:`、`file:` 等危险协议
- 非图片类型的 `data:` URL 会被拒绝
